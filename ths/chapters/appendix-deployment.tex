\section{Quick Start}

\subsection{Prerequisites}

\begin{itemize}
    \item Docker Desktop (any recent version)
    \item 8GB RAM available
    \item Ports 3000-9101 available
\end{itemize}

\subsection{Installation Steps}

\begin{listing}[H]
    \begin{minted}{bash}
# Clone repository
git clone https://github.com/Njoura7/ZK-Optimistic-rollups.git
cd ZK-Optimistic-rollups

# Build and start all services
docker-compose up --build

# Wait 2-3 minutes for initialization
    \end{minted}
    \caption{Basic deployment commands}
    \label{lst:deploy-commands}
\end{listing}

\section{Running Container State}

Figure~\ref{fig:docker-containers} shows Docker Desktop during a standard evaluation run. All four services start together: \texttt{zk-rollup-demo} (main application container running both sequencers, the Flask dashboard, and the Hardhat L1 node), \texttt{zk-prometheus} (metrics collection), and \texttt{zk-grafana} (visualization). Total memory footprint is approximately 870\,MB across all containers.
